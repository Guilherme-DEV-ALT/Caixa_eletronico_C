# Projeto Caixa Eletronico

Atividade introdutoria de algoritmos em C e Portugol.
O programa valida o saque, permite corrigir entradas invalidas e distribui
notas e moedas para valores ate R$600,00.

O codigo e a documentacao estao em [Projeto_Caixa](Projeto_Caixa/README.md).

## Compilar

Com o GCC instalado, execute na raiz do repositorio:

```powershell
gcc -std=c11 -Wall -Wextra Projeto_Caixa/caixa_eletronico.c -o Projeto_Caixa/caixa_eletronico.exe
```

## Executar

```powershell
.\Projeto_Caixa\caixa_eletronico.exe
```

O executavel e gerado localmente e nao faz parte do repositorio.
